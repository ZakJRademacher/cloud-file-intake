What should my CSV contain?

record_id,sale_date,category,quantity,unit_price_cents

Use text IDs, YYYY-MM-DD dates and integer cents. Cancellations use negative quantity. Known zeros are valid. File checks are deliberately limited to this small sales contract.

Why replay matters

Cloud events can arrive more than once. Identical file bytes and the same rule version reuse one verified result. Counts are never added to an accumulating total.

A changed file produces a separate job. This first version does not consolidate business records across different files.
